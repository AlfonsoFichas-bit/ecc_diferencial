# e) Análisis comparativo

- **Tabla por iteración:** columnas \(t\), \(C_{exacta}\), \(C_{Heun}\),
  \(C_{RK4}\), error absoluto Heun, error absoluto RK4, error relativo % Heun y
  RK4 (cuando el valor exacto ≠ 0).
- **Gráfica de concentración:** 3 curvas (analítica, Heun, RK4).
- **Gráfica de error absoluto:** 2 series (Heun y RK4 vs. analítica).
- **Comparación de al menos dos tamaños de paso:** resumen con número de pasos,
  error máximo absoluto y RMSE para \(h_1\) y \(h_2\).

El método RK4 presenta, en general, menor error que Heun para el mismo \(h\); al
reducir \(h\), ambos convergen a la solución analítica.
